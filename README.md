# 2026 추석맞이 가정예배

대한예수교장로회 일원중앙교회의 2026년 추석 가정예배용 웹페이지입니다.

## 바로가기

GitHub Pages로 배포하면 아래 주소에서 볼 수 있습니다.

https://rene8106.github.io/-2026/

## 담긴 파일

- `index.html` — 예배지 웹페이지 (외부 파일 없이 이 한 개로 동작합니다)
- `thumbnail.png` — 카카오톡 등으로 링크를 공유할 때 뜨는 미리보기 이미지

## 구성

- **예배 순서** — 묵도, 신앙고백, 찬송, 기도, 성경봉독, 설교, 가족합심기도, 주기도문
- **설교 전문** — 「감사가 풍성한 우리 가정」(골로새서 3:15~17)
- **가족 기도** — 가족합심기도, 공유·인쇄 기능

성경 본문은 화면 위쪽 버튼으로 개역개정과 새번역 중 골라 볼 수 있습니다.

## 올리는 방법

1. `index.html`과 `thumbnail.png`을 이 저장소 루트에 함께 올립니다.
2. 저장소 **Settings → Pages**에서 Branch를 `main`, 폴더를 `/(root)`로 선택하고 저장합니다.
3. 1분쯤 뒤 위 주소로 들어가 확인합니다.

## 문구 수정

저장소에서 `index.html`을 열고 연필 모양 아이콘을 누르면, 브라우저 안에서 바로 문구를 고치고 저장(Commit)할 수 있습니다.
